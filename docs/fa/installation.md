# راهنمای نصب و راه‌اندازی پارسی‌کیت

پارسی‌کیت کاملاً با زبان پایتون خالص (Pure Python) نوشته شده و هیچ وابستگی به کتابخانه‌های سنگین خارجی مانند C-extensions ندارد. بنابراین روی هر سیستم‌عاملی (لینوکس، ویندوز، مک‌او‌اس) به راحتی و در کسری از ثانیه نصب می‌شود.

---

## نیازمندی‌های سیستم

- پایتون **۳.۱۰** یا بالاتر (پشتیبانی رسمی از Python 3.10, 3.11, 3.12, 3.13)
- بدون نیاز به کامپایلر C یا ابزارهای جانبی

---

## ۱. نصب مستقیم با pip

ساده‌ترین راه برای نصب آخرین نسخه پایدار از مخزن PyPI:

```bash
pip install parsikit
```

یا اگر از ابزارهایی مثل Poetry یا uv استفاده می‌کنی:

```bash
# با استفاده از poetry
poetry add parsikit

# با استفاده از uv
uv add parsikit
```

---

## ۲. نصب از سورس پروژه (GitHub)

اگر می‌خواهی آخرین تغییرات توسعه یا نسخه مخزن را نصب کنی:

```bash
git clone https://github.com/MRThugh/ParsiKit.git
cd ParsiKit
pip install .
```

برای نصب در حالت توسعه و ادیت همزمان (Editable Mode):

```bash
pip install -e .
```

---

## تست نصب در پایتون

برای اطمینان از اینکه پارسی‌کیت درست نصب شده، ترمینال یا محیط تعاملی پایتون رو باز کن و این دو خط رو اجرا کن:

```python
import parsikit

print(parsikit.__version__)
# خروجی باید 3.3.1 باشد
```

اگر بدون خطا نسخه چاپ شد، تبریک می‌گیم! پارسی‌کیت آماده استفاده در پروژه‌هاته.
حالا می‌تونی به سراغ [راهنمای شروع سریع (Quickstart)](quickstart.md) بری.
