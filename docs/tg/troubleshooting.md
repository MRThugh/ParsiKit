# Роҳнамои рафъи мушкилот ва хатогиҳо (Troubleshooting)

Роҳҳои ҳалли мушкилоти маъмуле, ки ҳангоми истифодаи ParsiKit рух дода метавонанд:

---

## 1. Хатогии SyntaxError дар Python 3.10 ва 3.11

### Сабаби мушкилот
Пеш аз баромади Python 3.12, гузоштани аломати хатти моили чаппа (`\`) дар дохили ифодаҳои f-string аз ҷониби грамматикаи Python манъ буд (PEP 701). Дар версияи v3.3.0 дар функсияи `debug_text` чунин ифода мавҷуд буд, ки дар Python 3.10 ва 3.11 боиси хатогӣ мегардид.

### Роҳи ҳал
Ин камбудӣ дар версияи v3.3.1 комилан бартараф карда шуд. Китобхонаро навсозӣ намоед:
```bash
pip install --upgrade parsikit
```

---

## 2. Намоиши нодурусти аломатҳо ё аломати савол дар терминал

### Сабаби мушкилот
Ҳангоме ки рамзгузории (Encoding) баромади консол ба UTF-8 таъин нашудааст, аломатҳо метавонанд ба шакли аломати савол ё рамзҳои нохоно намоиш дода шаванд.

### Роҳи ҳал
Рамзгузории муҳити кориро ба UTF-8 танзим намоед:

Дар Linux ва macOS:
```bash
export PYTHONIOENCODING=utf-8
```

Дар Windows PowerShell:
```powershell
$env:PYTHONIOENCODING="utf-8"
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

## 3. Ҷудо мондан ё чаппа шудани ҳарфҳо дар Pillow ё OpenCV

### Сабаби мушкилот
Муҳаррикҳои графикии дученака (2D) ба таври пешфарз пайвастшавии хатти шарқӣ ва алгоритми дусамтаи Юникодро (BiDi) пуштибонӣ намекунанд ва матнро аз чап ба рост бо ҳарфҳои алоҳида расм мекунанд.

### Роҳи ҳал
Аз модули бозсозии ParsiKit истифода намоед:
```python
import parsikit

raw = "Коркарди тасвир"
reshaped = parsikit.reshape_for_graphics(raw)
# Сатри reshaped-ро ба функсияи расмкашӣ равона созед
```

## 4. Истиснои `InvalidNationalCodeError` барои воридоти 10-рақама

### Сабаби мушкилот
Рақами 10-рақама дар ҳолатҳои зерин қабул намешавад:
1. Ҳамаи рақамҳо якхела бошанд (масалан `1111111111`).
2. Рақами охирин (даҳум) ба чек-сами алгоритми математикии тақсим ба 11 мувофиқат накунад.

### Роҳи ҳал
Боварӣ ҳосил кунед, ки рақами санҷишӣ дуруст ҳисоб карда шудааст (масалан барои рақамҳои аввали `001012345`, рақами чек-сами дуруст `8` мебошад: `0010123458`).
