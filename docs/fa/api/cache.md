# مرجع ماژول کش (`parsikit.cache`)

زیرساخت کشینگ حافظه‌ای با کارایی بالا و ایمن در برابر چندریسمانی (Thread-safe) برای محاسبات پرهزینه عددی و زبانی.

---

## ۱. معرفی و کاربرد

ماژول `parsikit.cache` سازوکار کشینگ مبتنی بر الگوریتم شبه-LRU را فراهم می‌کند که به صورت داخلی در توابعی با بار پردازشی تکراری نظیر تبدیل اعداد بسیار بزرگ به حروف (`parsikit.number.number_to_words`) مورد استفاده قرار می‌گیرد.

> **نکته درباره پایداری ماژول:** این ماژول در درجه اول یک ماژول زیرساختی (Internal Infrastructure) برای خود کتابخانه است. با این حال کلاس‌ها و دکوراتورهای آن پایدار و در پروژه‌های شما نیز به صورت مستقل قابل استفاده هستند.

---

## ۲. کلاس‌ها

### `ThreadSafeLRUCache`

```python
class ThreadSafeLRUCache:
    def __init__(self, maxsize: int = 1024) -> None
```

کش سبک و محافظت‌شده با قفل `threading.Lock` در حافظه رم.

#### متدها:
- **`get(key: tuple) -> Any | None`**: مقدار کلید را بازمی‌گرداند و جایگاه کلید را در لیست دسترسی‌های اخیر تازه می‌کند. در صورت عدم وجود، `None` می‌دهد.
- **`set(key: tuple, value: Any) -> None`**: مقدار را ذخیره می‌کند. در صورتی که تعداد آیتم‌ها از `maxsize` فراتر رود، قدیمی‌ترین آیتم بدون استفاده را حذف می‌کند.
- **`clear() -> None`**: کل مقادیر کش را پاکسازی و ریست می‌کند.

## ۳. دکوراتورها

### دکوراتور `@memoize`

```python
from parsikit.cache import memoize

@memoize(maxsize=1024)
def my_func(a, b):
    ...
```

دکوراتور پایتونی برای به خاطر سپردن (Memoization) خروجی توابع خالص به ازای ورودی‌های مشخص.

#### قابلیت‌های کلیدی:
1. **هماهنگی با پیکربندی سراسری:** وضعیت `parsikit.config.enable_cache` را بررسی می‌کند. اگر روی `False` باشد، کش را دور می‌زند و مستقیماً تابع اصلی را فراخوانی می‌کند.
2. **ایمنی در محیط‌های چندنخی:** برای وب‌سرورهای چندنخی (FastAPI ،Flask یا ردهای Django) کاملاً ایمن است.
3. **کلیدهای ترکیبی:** کلیدها را از آرگومان‌های موقعیتی و آرگومان‌های کلیدواژه‌ای مرتب‌شده تولید می‌کند.

#### مثال کاربردی:

```python
import parsikit
from parsikit.cache import memoize

@memoize(maxsize=256)
def calculate_vat_report(invoice_id: int, rate: float = 0.10) -> dict:
    # محاسبات سنگین دیتابیسی یا ریاضی
    return {"id": invoice_id, "tax": 150000}

# فراخوانی اول تابع را اجرا کرده و خروجی را کش می‌کند
result1 = calculate_vat_report(1024)

# فراخوانی دوم بلافاصله از حافظه رم برگردانده می‌شود
result2 = calculate_vat_report(1024)

# خاموش کردن موقت کش
parsikit.config.enable_cache = False
result3 = calculate_vat_report(1024)  # تابع مجدداً اجرا می‌شود
parsikit.config.reset_defaults()
```

## ۴. نکات و محدودیت‌ها

- **ورودی‌های Hashable:** آرگومان‌های تابعی که با `@memoize` تزیین شده است باید قابلیت هش‌شدن (مانند int، str، tuple) داشته باشند. ارسال دیکشنری یا لیست خطا می‌دهد.
- **ایزولاسیون پردازه‌ها:** کش در سطح حافظه رم یک پردازه عمل می‌کند و در مدل چندپردازه‌ای (مانند چندین Worker در Gunicorn) هر پردازه کش مستقل خود را دارد.
