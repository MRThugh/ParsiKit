# مرجع کامل توابع و ماژول‌های پارسی‌کیت (API Reference)

کتابخانه **پارسی‌کیت (ParsiKit)** از ماژول‌های زیر تشکیل شده است:

| ماژول | توضیح مختصر | مستندات تفصیلی |
|---|---|---|
| `parsikit.text` | استانداردسازی نویسه‌ها، اصلاح نیم‌فاصله‌ها، حذف اعراب، استخراج اطلاعات و ماسک‌گذاری | [مستندات متنی](text.md) |
| `parsikit.validators` | اعتبارسنجی کد ملی، شماره موبایل، تلفن ثابت، شماره کارت، شبا، شناسه قبض و پلاک | [مستندات اعتبارسنجی](validators.md) |
| `parsikit.models` | مدل‌های شیءگرای غنی برای داده‌های هویتی، مالی و متنی (پشتیبانی از Pydantic) | [مستندات مدل‌ها](models.md) |
| `parsikit.datetime` | تبدیل تاریخ جلالی به میلادی و برعکس، محاسبه سال‌های کبیسه، اسامی ماه‌ها و زمان نسبی | [مستندات تاریخ و زمان](datetime.md) |
| `parsikit.number` و `parsikit.currency` | تبدیل ارقام فارسی و انگلیسی، عدد به حروف، تبدیل ریال و تومان، ارزش افزوده و اقساط | [مستندات اعداد و ارز](number_and_currency.md) |
| `parsikit.dev` و `parsikit.gui` | قالب‌بندی متنی هم‌تراز با فونت فارسی، عیب‌یابی متن و فرم‌های تعاملی گرافیکی | [مستندات ابزارهای توسعه و GUI](dev_and_gui.md) |
| `parsikit.reshaper` | چسباندن حروف متصل فارسی و معکوس‌سازی جهت متن برای موتورهای گرافیکی | [مستندات بازآرایی گرافیکی](reshaper.md) |
| `parsikit.cache` | زیرساخت کشینگ چندریسمانی با کارایی بالا در حافظه رم | [مستندات کشینگ](cache.md) |
| `parsikit.config` و `parsikit.exceptions` | تنظیمات سراسری پکیج و درخت استثناهای ساختاریافته اعتبارسنجی | [توضیحات استثناها و تنظیمات](#تنظیمات-و-استثناها) |

---

## تنظیمات و استثناها

### ۱. تنظیمات سراسری (`parsikit.config`)
- `default_tax_rate`: نرخ پیش‌فرض مالیات بر ارزش افزوده (پیش‌فرض: `0.10`).
- `default_currency`: واحد پول پیش‌فرض سیستم، `"toman"` یا `"rial"` (پیش‌فرض: `"toman"`).
- `enable_cache`: فعال یا غیرفعال‌سازی کش پرسرعت برای تبدیل اعداد و کلمات (پیش‌فرض: `True`).

### ۲. سلسله‌مراتب خطاهای اعتبارسنجی (`parsikit.exceptions`)
تمام خطاهای پارسی‌کیت از `ParsiKitError` و `ValidationError` ارث‌بری می‌کنند:
- `InvalidNationalCodeError`
- `InvalidMobileError`
- `InvalidCardNumberError`
- `InvalidShebaError`
- `InvalidPostalCodeError`
- `InvalidPlateError`
- `InvalidBillError`
