# Маълумотномаи модули кэш (`parsikit.cache`)

Зерсохтори нигаҳдории муваққатӣ дар хотира (In-Memory Cache) бо суръати баланд ва амнияти комил дар баробари риштаҳои ҳамзамон (Thread-safe) барои оптимизатсияи ҳисобҳои вазнин.

---

## Тавсифи умумӣ

Модули `parsikit.cache` механизмҳои нигаҳдории муваққатии LRU-ро дар хотираи оперативӣ таъмин мекунад, ки аз ҷониби функсияҳои вазнини монанди `parsikit.number.number_to_words` истифода мешаванд.

---

## Синфҳо (Classes)

### `ThreadSafeLRUCache`

```python
class ThreadSafeLRUCache:
    def __init__(self, maxsize: int = 1024) -> None
```

Кэши сабук дар хотира, ки бо қулфи бозворидии `threading.RLock` муҳофизат шудааст, то дастрасии бехатари ҳамзамон ва рекурсивиро таъмин намояд.

#### Қоидаҳои ғунҷоиш (Capacity Rules)
- `maxsize` бояд адади бутун (`int`) бошад. Дар сурати ғайр хатогии `TypeError` рух медиҳад.
- `maxsize >= 0`. Ададҳои манфӣ боиси `ValueError` мешаванд.
- `maxsize == 0`: Дар ҳолати бидуни захирасозӣ амал мекунад.

#### Методҳо ва хосиятҳо
- **`get(key: Any, default: Any = None) -> Any`**: Дарёфти қимат аз кэш ва навсозии мавқеи калид ҳамчун охирин истифодашуда (MRU).
- **`set(key: Any, value: Any) -> None`**: Илова ё навсозии қимат дар кэш бо хориҷ кардани кӯҳнатарин ашё дар сурати пур будани ғунҷоиш.
- **`clear() -> None`**: Тоза кардани тамоми иттилоот ва аз нав баргардонидани омор.
- **`pop(key: Any, default: Any = ...) -> Any`**: Хориҷ ва бозпас гирифтани қимати калид.
- **`keys_order`**: Рӯйхати калидҳои захирашуда аз кӯҳнатарин то тозатарин.
- **`__len__()` ва `__contains__(key)`**: Ҳисоби теъдоди ашё ва санҷиши мавҷудияти калид.

## Декораторҳо (Decorators)

### `@memoize`

```python
def memoize(maxsize: int = 1024) -> Callable[[Callable[..., _T]], Callable[..., _T]]
```

Декораторе, ки натиҷаи иҷрои функсияро бо истифода аз нусхаи махсуси `ThreadSafeLRUCache` нигоҳ медорад.

#### Хусусиятҳо
- **Мутобиқат бо танзимоти саросарӣ**: Тағйирёбандаи `parsikit.config.enable_cache`-ро тафтиш карда, дар сурати хомӯш будан, функсияро мустақиман иҷро менамояд.
- **Амнияти риштагӣ**: Бо истифода аз `threading.RLock` аз ихтилофи риштаҳо ҷилавгирӣ мешавад.
- **Дастгирии аргументҳои Unhashable**: Ҳангоми гирифтани рӯйхатҳо ё луғатҳо, кэшкунӣ бидуни партофтани хатогии `TypeError` гузаронида шуда, функсия муқаррарӣ иҷро мегардад.
- **Методҳои назоратӣ**:
  - `func.cache`: Истинод ба объекти кэш.
  - `func.cache_clear()`: Поксозии кэш ва сифр кардани ҳисобкунакҳо.
  - `func.cache_info()`: Баргардонидани тапли `CacheInfo(hits, misses, maxsize, currsize)`.
