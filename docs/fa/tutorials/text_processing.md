# آموزش جامع پردازش و تمیزکاری متن فارسی در پارسی‌کیت

پردازش متن فارسی چالش‌های منحصر‌به‌فردی داره: اعراب‌ها، حروف کیبورد عربی، نیم‌فاصله‌ها و نگارش انگلیسی در کیبورد فارسی. پارسی‌کیت مجموعه‌ای از توابع کارآمد برای حل این دغدغه‌ها در اختیارت می‌ذاره.

---

## ۱. استانداردسازی حروف (`standardize_persian`)

این تابع نویسه‌های عربی رو به معادل رسمی فارسی تبدیل می‌کنه:
- «ي» و «ى» به «ی»
- «ك» به «ک»
- «ة» به «ه»
- اصلاح نیم‌فاصله‌های پیشوندهای «می»، «نمی»، «بی» و پسوندهای «ها»، «تر»، «ترین»
- حذف نیم‌فاصله‌های پشت سر هم و تکراری

```python
import parsikit

raw = "مشتري ها ميباشد كه كتاب ها را ميخوانند"
clean = parsikit.standardize_persian(raw)
print(clean)
# 'مشتری‌ها میباشد که کتاب‌ها را می‌خوانند'
```

همچنین اگر خواستی اعراب‌ها (فتحه، کسره، ضمه، تنوین و...) همزمان حذف بشن:
```python
clean_no_vowel = parsikit.standardize_persian("کِتاب‌هایِ ما", strip_diacritics_opt=True)
print(clean_no_vowel)  # 'کتاب‌های ما'
```

---

## ۲. حذف اعراب (`strip_diacritics`)

اگر فقط می‌خواهی تنوین، تشدید و حرکات رو حذف کنی بدون اینکه تغییری در بقیه متن داده بشه:

```python
clean = parsikit.strip_diacritics("سَلامٌ عَلَيْكُمْ وَ رَحْمَةُ اللهِ")
print(clean)
# 'سلام علیکم و رحمة الله'
```

## ۳. اصلاح چینش اشتباه کیبورد (`correct_keyboard_layout`)

حتماً تا حالا برات پیش اومده که به جای «سلام» اشتباهاً کیبورد انگلیسی بوده و نوشتی «sghl»:

```python
fixed = parsikit.correct_keyboard_layout("sghl nhka[,dhk uvdoc!")
print(fixed)
# 'سلام دانشجویان عزیز!'
```

## ۴. مرتب‌سازی الفبایی فارسی (`persian_sorted` و `persian_sort_key`)

پایتون به طور پیش‌فرض مرتب‌سازی رو بر اساس کد اسکی کاراکترها انجام می‌ده که باعث می‌شه حروفی مثل «گ، چ، پ، ژ» در جای اشتباهی از لیست قرار بگیرن. پارسی‌کیت وزن الفبای رسمی فارسی رو اعمال می‌کنه:

```python
words = ["سیب", "انار", "به", "پرتقال", "آلو", "چای"]

# مرتب‌سازی اشتباه پایتون پیش‌فرض:
print(sorted(words))

# مرتب‌سازی استاندارد با پارسی‌کیت:
sorted_words = parsikit.persian_sorted(words)
print(sorted_words)
# ['آلو', 'انار', 'به', 'پرتقال', 'چای', 'سیب']
```

## ۵. زیباسازی فاصله‌ها و علائم نگارشی (`beautify_persian_spacing`)

علامت‌های نگارشی فارسی نباید قبل خودشون فاصله داشته باشن، اما بعدشون باید دقیقاً یک فاصله باشه. این تابع پرانتزها، ویرگول، نقطه و علامت سوال رو استاندارد می‌کنه:

```python
text = "این یک متن است ,که با عجله تایپ شده ( بدون توجه به فاصله ) ."
beautified = parsikit.beautify_persian_spacing(text)
print(beautified)
# 'این یک متن است، که با عجله تایپ شده (بدون توجه به فاصله).'
```

## ۶. تبدیل متن به نامک انگلیسی/فینگلیش (`slugify`)

برای ساختن آدرس URL تمیز در وب‌سایت‌ها:

```python
slug = parsikit.slugify("آموزش جامع وردپرس نسخه 6")
print(slug)
# 'amoozesh-wordpress-neskheh-6'
```

کلمات پرکاربرد مانند «آموزش»، «سایت»، «مقاله»، «نسخه» و «وردپرس» از دیکشنری هوشمند فینگلیش ترجمه می‌شن و بقیه حروف کاراکتر به کاراکتر نگاشت می‌شن.

## ۷. ماسک کردن اطلاعات حساس

برای محافظت از حریم خصوصی در لاگ‌ها یا پیامک‌ها:

```python
# ماسک کردن موبایل (نمایش ۴ رقم اول و ۴ رقم آخر)
print(parsikit.mask_mobile("09123456789"))  # '0912***6789'

# ماسک کردن کارت بانکی (حفظ ۶ رقم اول پیش‌شماره بانک و ۴ رقم آخر)
print(parsikit.mask_card("6037991122334455"))  # '6037-99**-****-4455'

# ماسک کردن کد ملی
print(parsikit.mask_national_code("7730123452"))  # '773-****45-2'

# ماسک کردن ایمیل
print(parsikit.mask_email("kamrani.exe@gmail.com"))  # 'ka********e@gmail.com'
```
