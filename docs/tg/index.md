# Ҳуҷҷатгузории расмии ParsiKit (версияи 3.3.1)

Салом таҳиягари гиромӣ! Ба ҳуҷҷатгузории расмии китобхонаи **ParsiKit** хуш омадед.  
Ин лоиҳа аз ҷониби **Алӣ Комронӣ (Ali Kamrani / MRThugh)** бо мақсади сохтани як зерсохтори мукаммал, стандартӣ, баландсуръат ва холиси Python барои коркарди додаҳо ва матнҳо офарида шудааст.

---

## ParsiKit чист ва чӣ корбурдҳое дорад?

Ҳангоми кор бо додаҳои матнӣ ва рақамӣ дар Python, барномасозон ҳамеша бо чунин мушкилот рӯ ба рӯ мешаванд:
- Ҳарфҳои номувофиқ аз сабаби тарҳбандии гуногуни сафҳакалидҳо (ба мисли истифодаи «ي» ва «ك»-и арабӣ ба ҷои ҳарфҳои расмӣ), ки ҷустуҷӯро дар пойгоҳи додаҳо қатъ месозад.
- Набудани нимафосилаҳои дуруст (ZWNJ) барои пешвандҳо (монанди «ме») ва пасвандҳо (монанди «ҳо»).
- Омезиши рақамҳои англисӣ ва шарқӣ дар матнҳо ва ҳисобномаҳо.
- Зарурати санҷиши эътибори рақамҳои кортҳои бонкӣ, рамзҳои миллӣ, суратҳисобҳои байналмилалӣ (IBAN), рақамҳои нақлиёт ва рамзҳои почта.
- Ниёз ба табдили дақиқи санаҳои милодӣ ба тақвими ҳиҷрии шамсӣ ва муайян кардани солҳои кабиса.
- Ҳисоби маблағҳо, андоз аз арзиши иловашуда ва табдили рақамҳо ба калимаҳои хаттӣ.

**ParsiKit** ҳамаи ин талаботро дар як бастаи сабук ва холиси Python (Pure Python) бидуни ҳеҷ гуна вобастагии беруна (Zero-Dependency) таъмин менамояд.

---

## Маҳдудиятҳои корбарии ParsiKit

Фаҳмидани доираи масъулияти китобхона хеле муҳим аст:
1. **Санҷиши дурустии сохтор ва алгоритми чек-сам, на санҷиши шахсият:**  
   Функсияи `is_valid_national_code` танҳо дарозӣ ва дурустии математикии чек-самро месанҷад. Китобхона ба пойгоҳи давлатии сабти асноди шаҳрвандӣ пайваст нест ва шахсияти соҳиби рамзро тасдиқ намекунад.
2. **Санҷиши корти бонкӣ дар асоси алгоритми Лун (Luhn):**  
   ParsiKit дурустии рақами 16-рақамаро аз рӯи алгоритми Лун тасдиқ карда, бонки содиркунандаро аз рӯи 6 рақами аввал муайян мекунад, аммо бақияи ҳисоб ё баста будани кортро тафтиш карда наметавонад.
