# Маълумотномаи модули сана ва вақт (`parsikit.datetime`)

Функсияҳои табдили тақвими ҳиҷрии шамсӣ (ҷалолӣ) ва милодӣ, муайян кардани соли кабиса ва ифодаи вақти нисбӣ:

---

## Функсияҳои асосӣ

### `gregorian_to_jalali(gy: int, gm: int, gd: int) -> tuple[int, int, int]`
Табдили санаи милодӣ (сол, моҳ, рӯз) ба санаи шамсӣ бо дақиқияти астрономӣ. Моҳ (1 то 12) ва рӯз (1 то 31) санҷида шуда, дар сурати нодуруст будан `ValueError` медиҳад.

### `jalali_to_gregorian(jy: int, jm: int, jd: int) -> tuple[int, int, int]`
Табдили санаи шамсӣ (сол, моҳ, рӯз) ба муодили милодӣ бо санҷиши ҳудуди моҳ ва рӯз.

### `is_jalali_leap(jy: int) -> bool`
Санҷиши 366-рӯза будан (соли кабиса) дар тақвими шамсӣ.

### `get_jalali_month_name(month: int) -> str`
Баргардонидани номи моҳи шамсӣ аз рӯи шумораи моҳ (1 то 12).

### `format_jalali(jy: int, jm: int, jd: int, pattern: str = "YYYY/MM/DD", *, persian_digits: bool = False) -> str`
Қолаббандии санаи шамсӣ тибқи намунаи додашуда (бо имкони `persian_digits=True` барои рақамҳои шарқӣ).

### `humanize_relative_time(dt_or_seconds, reference=None) -> str`
Табдили фарқияти вақт ё объекти `datetime` ба ибораи фаҳмои табиӣ (масалан `'ҳоло'`, `'15 дақиқа пеш'`, `'дирӯз'`, `'дар 2 соати оянда'`).
