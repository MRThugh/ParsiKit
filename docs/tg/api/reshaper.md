# Маълумотномаи модули бозсозии хат (`parsikit.reshaper`)

Модули сабук ва бидуни вобастагӣ барои пайваст кардани ҳарфҳо ва идораи матни дусамта (BiDi) дар муҳаррикҳои графикӣ ва бозиҳо.

---

## Тавсифи умумӣ

Бисёре аз муҳаррикҳои графикӣ (ба мисли Pygame, OpenCV, Pillow бидуни Raqm) матнҳоро танҳо аз чап ба рост расм мекунанд, ки ин боиси ҷудо ва чаппа навишта шудани ҳарфҳо мегардад (масалан `س ل ا م`).

Модули `parsikit.reshaper` аломатҳои Юникодро ба ҳолатҳои пайваста табдил дода, самти дурусти намоишро ба танзим медарорад.

---

## Функсияҳои асосӣ

### `reshape_for_graphics(text: str, reverse: bool = True) -> str`

Ҳарфҳои матнро пайваст карда, тартиби хонишро танзим месозад.

#### Параметрҳо:
- **`text`** (`str`): Сатри матнии воридотӣ.
- **`reverse`** (`bool`, пешфарз `True`): Агар `True` бошад, тартиби аломатҳоро барои муҳаррикҳои чап-ба-рост чаппа мекунад, то дуруст хонда шаванд, дар ҳоле ки калимаҳои лотинӣ ва рақамҳо бидуни тағйир дар самти дуруст мемонанд.

#### Натиҷа:
- `str`: Сатри бозсозишуда барои расмкашӣ дар тасвир.

---

### `reshape_paragraph_for_graphics(text: str, max_chars_per_line: int, reverse: bool = True) -> list[str]`

Бандҳои дарози матниро бо назардошти калимаҳо тақсим карда, ҳар як сатрро барои расмкашии графикӣ омода месозад.

#### Параметрҳо:
- **`text`** (`str`): Матн барои тақсимбандӣ.
- **`max_chars_per_line`** (`int`): Ҳадди аксари паҳнои рамзҳо дар як сатр.
- **`reverse`** (`bool`): Самти чаппакунӣ.

#### Натиҷа:
- `list[str]`: Рӯйхати сатрҳои омодашуда.
