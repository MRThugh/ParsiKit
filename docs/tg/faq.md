# Саволҳои маъмул (FAQ)

### 1. ParsiKit аз кадом версияҳои Python пуштибонӣ мекунад?
ParsiKit аз Python версияи **3.10 ва болотар** (аз ҷумла 3.10, 3.11, 3.12 ва 3.13) комилан пуштибонӣ менамояд.

---

### 2. Оё ParsiKit вобастагиҳои беруна дорад?
Не. ParsiKit 100% бо забони тозаи Python (Pure Python) навишта шудааст ва ҳеҷ гуна вобастагии иҷроии беруна надорад. Аз ин рӯ, он фавран насб мешавад ва фазои хеле камро ишғол мекунад.

---

### 3. ParsiKit аз дигар абзорҳо (ба мисли Hazm) чӣ фарқ дорад?
- **Hazm** ба коркарди забони табиӣ (NLP), таҳлили морфологӣ ва грамматикӣ нигаронида шудааст.
- **ParsiKit** як зерсохтори умумии нармафзорӣ барои системаҳои веб, ҳисобҳои молиявӣ, пойгоҳҳои додаҳо, санҷиши эътибори ҳуҷҷатҳо ва амнияти маълумоти ҳассос мебошад.

---

### 4. Оё ParsiKit дар муҳитҳои бисёрриштагӣ (Thread-safe) бехатар аст?
Бале. Танзимоти саросарӣ ва кэши дохилии китобхона бо истифода аз қулфҳои бозворидии Python (`threading.RLock`) ҳифз карда мешаванд ва дар веб-серверҳои бисёрриштагӣ ба монанди Gunicorn ва Uvicorn бехатар фаъолият мекунанд.

---

### 5. Оё ParsiKit маълумоти шахсии корбаронро дар логҳо ифшо мекунад?
Не. Дар версияи 3.3.1 ҳамаи истисноҳои махсус (монанди `InvalidCardNumberError`) паёмҳоро поксозӣ карда, ҳамаи моделҳо хосияти `.masked`-ро барои сабти бехатар дар логҳо ва панелҳои идоракунӣ фароҳам овардаанд.

---

### 6. Иҷозатномаи истифодаи ин нармафзор чист?
ParsiKit таҳти иҷозатномаи озод ва эътирофшудаи **MIT** нашр шудааст. Шумо метавонед онро дар ҳама гуна лоиҳаҳои тиҷоратӣ, кушодаасос ва шахсӣ озодона истифода баред.
