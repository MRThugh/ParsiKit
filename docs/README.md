# ParsiKit Documentation Hub / هاب مستندات پارسی‌کیت / Маркази ҳуҷҷатгузорӣ

Welcome to the documentation for **ParsiKit** (v3.3.1), a pure Python library for Persian and regional data infrastructure, created and maintained by **Ali Kamrani (MRThugh)**.

---

## Language Selection / انتخاب زبان / Интихоби забон

- 🇮🇷 **[مستندات فارسی (Iranian Persian Documentation)](fa/index.md)**  
  راهنمای جامع، خودآموزهای گام‌به‌گام و مرجع کامل توابع به زبان فارسی روان و استانداردهای ایران.

- 🇦🇫 **[مستندات دری (Afghan Dari Documentation)](fa-AF/index.md)**  
  رهنمود همه‌جانبه، آموزش‌های گام‌به‌گام و مرجع کامل توابع به زبان دری متناسب با استانداردهای افغانستان.

- 🇹🇯 **[Ҳуҷҷатгузории тоҷикӣ (Tajikistan Tajik Documentation)](tg/index.md)**  
  Роҳнамои мукаммал, дастурҳои омӯзишӣ ва маълумотномаи функсияҳо бо хатти сириллики расмии тоҷикӣ.

- 🇬🇧 **[English Documentation](en/index.md)**  
  Complete guides, step-by-step tutorials, and full API reference in technical English.
