# Маълумотномаи модули коркарди матн (`parsikit.text`)

Маҷмӯаи абзорҳои стандартсозии матн, танзими нимафосилаҳо, поксозӣ, сохтани слаг ва ниқоббандии додаҳои ҳассос.

---

## Стандартсозӣ ва поксозии матн

### `standardize_persian(text: str, *, strip_diacritics_opt: bool = False, preserve_arabic: bool = False) -> str`
Матнҳои воридотиро тибқи қоидаҳои имлоӣ ба тартиб медарорад:
- Табдили ҳарфҳои арабии «ي» ва «ك» ба ҳарфҳои мувофиқ («ی» ва «ک»).
- Ҳифзи аломатҳои курдӣ (монанди `ە`) ва ҳифзи матнҳои арабӣ дар сурати фаъол будани `preserve_arabic=True`.
- Танзими худкори нимафосилаҳо (ZWNJ) барои пешвандҳо ва пасвандҳо.
- Ҳазфи нимафосилаҳои саргардон, такрорӣ ё часпондашуда ба аломатҳои китобатӣ.
- Тоза кардани фосилаҳои изофӣ бидуни вайрон кардани сохтори бандҳо.

### `strip_diacritics(text: str) -> str`
Ҳазфи эъроб ва ҳаракатҳо (фатҳа, замма, касра, танвин, ташдид, сукун).

### `is_persian(text: str) -> bool`
Санҷиши мавҷудияти ақаллан як ҳарф аз алифбо дар матн.

### `clean_text(text: str, *, preserve_arabic: bool = False) -> str`
Поксозии ҳамаҷонибаи матн бо ҳифзи суроғаҳои интернетӣ (URL), почтаи электронӣ (email) ва рамзҳои техникӣ.

### `normalize_whitespace(text: str, keep_paragraphs: bool = True) -> str`
Ҳамоҳангсозии фосилаҳои ностандартӣ. Дар сурати `keep_paragraphs=False` тамоми матн ба як сатри пайваста табдил меёбад.

### `beautify_persian_spacing(text: str) -> str`
Танзими фосилаҳои дуруст дар атрофи аломатҳои китобатӣ (вергул, нуқтавергул, қавсҳо, нохунакҳо) бо ҳифзи дақиқи URL, email ва рақамҳои даҳӣ.

### `smart_persian_spacing(text: str, preserve_urls: bool = True, preserve_quotes: bool = True) -> str`
Танзими ҳушманди нимафосилаҳо ва фосилагузорӣ дар пешвандҳо ва пасвандҳои феълӣ ва исмӣ бо ҳифзи пурраи истинодҳои интернетӣ ва иқтибосҳо.

---

## Сафҳакалид ва мураттабсозӣ (Sorting)

### `correct_keyboard_layout(text: str, to: Literal["persian", "english", "auto"] = "persian", preserve_mixed: bool = False) -> str`
Ислоҳи дутарафаи калимаҳое, ки бо забони нодурусти сафҳакалид навишта шудаанд:
- `to="persian"`: табдили тугмаҳои лотинӣ ба ҳуруфи форсӣ (масалан `"sghl"` ба `"سلام"`).
- `to="english"`: табдили тугмаҳои форсӣ ба муодили QWERTY лотинӣ (масалан `"اثممخ"` ба `"hello"`).
- `to="auto"`: ташхиси худкори самти табдилдиҳӣ.

### `expand_snippets(text: str, snippets: dict[str, str], word_boundary: bool = True) -> str`
Ивазкунии фаврии ихтисорот ба ибораҳои пурраи расмӣ (масалан `{"қ.з": "қабл аз зӯҳр"}`).

### `persian_sort_key(s: str) -> tuple[int, ...]`
Тавлиди калиди ҷобаҷокунии алифбоӣ тибқи тартиби расмӣ.

### `persian_sorted(iterable: Iterable[T], *, reverse: bool = False) -> list[T]`
Мураттабсозии рӯйхати сатрҳо дар асоси калиди олии алифбоӣ.

---

## Истихроҷ ва табдил

### `normalize_digits(text: str, to: Literal["persian", "english", "arabic"] = "persian") -> str`
Якнавохтсозии рақамҳои матн ба яке аз системаҳои `"persian"`, `"english"`, ё `"arabic"`.

### `words_to_number(text: str) -> int`
Табдили ададҳои бо калимаҳо навишташуда ба рақамҳои математикӣ (масалан табдили `"سی و دو هزار و پانصد"` ба `32500`).

### `convert_numbers(text: str, to: Literal["persian", "english"] = "persian") -> str`
Табдили рақамҳои дохили матн миёни хатти лотинӣ ва шарқӣ.

### `slugify(text: str, separator: str = "-") -> str`
Тавлиди сатрҳои СЭО барои суроғаи вебсаҳифаҳо аз рӯи луғати транскрипсия.

### `extract_mobiles(text: str) -> list[str]`
Истихроҷи ҳамаи рақамҳои дурусти телефони мобилӣ аз дохили матн.

### `extract_national_codes(text: str) -> list[str]`
Истихроҷи ҳамаи рамзҳои миллии 10-рақамаи дуруст аз матн.

---

## Ниқоббандии иттилооти маҳрамона (Masking)

### `mask_mobile(phone: str, mask_char: str = "*") -> str`
Ниқоббандии рақамҳои мобайнии телефон (масалан `"0912***6789"`).

### `mask_card(card: str, mask_char: str = "*") -> str`
Ниқоббандии қисми мобайни корти бонкии 16-рақама бо нигоҳ доштани гурӯҳбандии 4-тогӣ.

### `mask_national_code(code: str, mask_char: str = "*") -> str`
Ниқоббандии қисми мобайни рамзи миллӣ.

### `mask_email(email: str, mask_char: str = "*") -> str`
Ниқоббандии муносиби ҳарфҳои номи корбар дар суроғаи почтаи электронӣ.
