## 📖 معرفی پارسی‌کیت

کتابخانه‌ی **ParsiKit** (که توی کدهاتون به صورت `parsikit` ایمپورتش می‌کنید) یک ابزار همه‌فن‌حریف و بدون هیچ وابستگی خارجی (Zero-Dependency) هست که طراحی شده تا تمام چالش‌های کار با داده‌های فارسی در برنامه‌نویسی را حل کنه.

توی نسخه **v3.3.0**، پارسی‌کیت از یک ابزار ساده فراتر رفته و به یک **زیرساخت برنامه‌نویسی همه‌جانبه** تبدیل شده. حالا علاوه بر معماری شیءگرا و زیبای قبلی، ابزارهای پیشرفته عیب‌یابی متن، فرمت‌دهی هوشمند و سازگار با تراز بصری فارسی، ابزارهای امنیتی (ماسک کردن اطلاعات) و تشخیص خودکار نوع داده‌ها بهش اضافه شده تا بتونید کدهای تمیزتر، امن‌تر و حرفه‌ای‌تری بنویسید.

## 🚀 ستون‌های اصلی پارسی‌کیت در نسخه v3.3.0

### ۱. تنظیمات سراسری و کش سریع (`parsikit.config` و `parsikit.cache`)
* **کش سریع و امن**: کارهای سنگین پردازشی (مثل تبدیل رقم‌های خیلی بزرگ به حروف فارسی یا محاسبات تاریخی) به صورت خودکار با یک سیستم کش روان و امن (Thread-safe) بهینه‌سازی می‌شن تا سرعت برنامه‌تون به حداکثر برسه.
* **تنظیمات سراسری ساده**: نرخ مالیات، واحد پولی پیش‌فرض سیستم یا روشن/خاموش بودن کش رو به راحتی در کل پروژه مدیریت کنید.

### ۲. ارورهای ساختاریافته ایرانی (`parsikit.exceptions`)
دیگه نیازی نیست نگران مدیریت ارورهای کلی پایتون مثل `ValueError` یا `TypeError` باشید. پارسی‌کیت ارورهای اختصاصی و منطبق با استانداردهای ایرانی (مثل کد ملی نامعتبر، کارت بانکی اشتباه و...) رو در اختیارتون می‌ذاره که برای معماری‌های تمیز (Clean Architecture) فوق‌العاده‌ست.

### ۳. مدل‌های دامنه شیءگرا (`parsikit.models`)
رشته‌های خام ورودی رو داخل مدل‌های شیک و شیءگرا مثل `NationalCode` ،`MobileNumber` ،`BankCard` یا `VehiclePlate` قرار بدید. این مدل‌ها به محض ساخته شدن ورودی رو اعتبارسنجی می‌کنن و متدهای جذابی مثل تشخیص اپراتور سیم‌کارت، استان صدور کد ملی یا جزئیات بانک صادرکننده‌ی کارت رو به شما تحویل می‌دن.

### ۴. ابزارهای عیب‌یابی و تراز بصری فارسی (`parsikit.dev` - جدید در v3.3.0!)
* **تراز بصری متن‌ها (`pformat` و `persian_fstring`)**: در حالت عادی، پایتون پهنای متون حاوی نیم‌فاصله یا اعراب رو اشتباه حساب می‌کنه و تراز خروجی‌ها یا جدول‌های ترمینال به هم می‌ریزه. پارسی‌کیت با حساب کردن پهنای واقعی کاراکترها روی مانیتور، خروجی‌های کاملاً تراز شده تحویلتون میده.
* **عیب‌یابی هوشمند متن**: متون ورودی رو پایش کنید تا اگر کاراکترهای عربی مزاحم، نیم‌فاصله‌های فراموش‌شده یا فاصله‌های اضافی دارن، فوراً متوجه بشید و اصلاحشون کنید.

### ۵. پکیج امنیتی و پاکسازی پیشرفته (جدید در v3.3.0!)
* **اسلاگ‌ساز سئو (`slugify`)**: متون فارسی یا ترکیبی رو به اسلاگ‌های انگلیسی (Finglish) تمیز برای آدرس صفحات وب یا نام فایل‌ها تبدیل کنید (با ترجمه خودکار کلمات پرکاربرد مثل "سلام دنیا" به "salam-donya").
* **پاکسازی همه‌جانبه (`clean_text` و `normalize_whitespace`)**: فاصله‌های اضافی رو حذف کنید، خطوط خالی رو مرتب کنید، حروف عربی رو به فارسی برگردونید و کدهای نامرئی یونیکد رو از متن‌ها جارو کنید.
* **تشخیص‌دهنده هوشمند ورودی (`detect`)**: ورودی کاربر رو پایش کنید تا سیستم خودش بفهمه دیتای ورودی ایمیل هست، آی‌پی هست، آدرس وب‌سایت، شماره موبایل، شبا یا کارت بانکیه.
* **مخفی‌سازی اطلاعات حساس (`mask_*`)**: شماره موبایل، کد ملی، ایمیل یا کارت بانکی کاربرها رو قبل از نوشتن توی لاگ‌ها یا نمایش در پنل کاربری، به راحتی ماسک و ایمن کنید (مثل `0912***6789`).

## 🛠️ مدیریت تنظیمات سراسری و ارورها

### ۱. تنظیم سراسری رفتار کتابخانه
```python
import parsikit

# تنظیم سراسری نرخ مالیات بر ارزش افزوده (پیش‌فرض: 0.10)
parsikit.config.default_tax_rate = 0.09

# تنظیم واحد پولی پیش‌فرض در سراسر برنامه (پیش‌فرض: toman)
parsikit.config.default_currency = "rial"

# فعال‌سازی کش پردازشی برای سرعت بیشتر
parsikit.config.enable_cache = True
```

### ۲. ساختار ارورهای اختصاصی
همه ارورهای پارسی‌کیت از `ValidationError` ارث‌بری می‌کنن تا به راحتی بتونید خطاهای دیتای ورودی رو مدیریت کنید:
```python
import parsikit

try:
    card = parsikit.BankCard("invalid-card-number")
except parsikit.InvalidCardNumberError as e:
    print(f"شماره کارت اشتباه است: {e}")
except parsikit.ValidationError as e:
    print(f"یک خطای اعتبارسنجی رخ داد: {e}")
```

## 🦄 هماهنگی بومی با Pydantic v2 و FastAPI

شما می‌تونید کلاس‌های پارسی‌کیت رو مستقیماً به عنوان نوع فیلدها در اسکیماهای Pydantic یا ورودی متدهای FastAPI قرار بدید. کتابخانه خودش کار ولیدیشن، تبدیل فرمت و ارسال خطاهای تمیز به کاربر رو انجام میده:

```python
from fastapi import FastAPI
from pydantic import BaseModel
import parsikit

app = FastAPI()

class UserRegisterSchema(BaseModel):
    fullname: parsikit.PersianText
    national_id: parsikit.NationalCode
    phone: parsikit.MobileNumber
    card: parsikit.BankCard

@app.post("/register")
def register_user(user: UserRegisterSchema):
    # تمام داده‌ها از قبل ولیدیت، تمیز و استاندارد شدن!
    print(user.fullname.standardize()) # تصحیح ی/ک و نیم‌فاصله‌ها
    print(user.national_id.location)   # خروجی: {"province": "تهران", "city": "تهران مرکزی"}
    print(user.phone.to_international()) # خروجی: "+989123456789"
    
    # خروجی گرفتن به صورت دیکشنری پایتون
    return {
        "status": "success",
        "data": {
            "national_id": user.national_id.to_dict(),
            "card_bank": user.card.bank
        }
    }
```

## 🚀 راهنمای ویژگی‌ها و نمونه کدها

### ۱. دستیار توسعه‌دهنده و خطایاب متون (`parsikit.dev`)
پارسی‌کیت ابزارهای کارآمدی رو برای تست، خطایابی و نمایش متون فارسی در ترمینال فراهم کرده.

#### عیب‌یابی گام‌به‌گام متن
تک‌تک باگ‌های ساختاری متن رو پیدا کنید و راهکار اصلاحش رو تحویل بگیرید:
```python
import parsikit

# بررسی خطاهای یونیکد و نیم‌فاصله
analysis = parsikit.inspect_text("ي كافيه ك کتاب ها ميباشد ۱۲۳")
print(analysis["has_arabic_chars"]) # خروجی: True (به خاطر ي و ك عربی)
print(analysis["has_zwnj_issues"])  # خروجی: True (به خاطر "کتاب ها" و "ميباشد")
print(analysis["suggestions"])
# خروجی: لیستی از راهکارهای پیشنهادی برای تصحیح حروف عربی، نیم‌فاصله‌ها و تبدیل اعداد

# چاپ گزارش رنگی و شکیل در ترمینال
parsikit.debug_text("ي كافيه ك کتاب ها ميباشد")
```

#### نمایش خوانای فارسی در لاگ‌ها و ترمینال
در حالت عادی، پایتون متون فارسی داخل لیست یا دیکشنری رو به صورت کدهای ناخوانای یونیکد (مثل `\u0627`) نشون میده. پارسی‌کیت این مشکل رو حل کرده:
```python
import parsikit

data = {"کاربر": ["امیر", "رضا"], "وضعیت": True}

# خروجی پایتون در حالت عادی ناخواناست، اما با ابزار ما:
print(parsikit.persian_repr(data))
# خروجی: {'کاربر': ['امیر', 'رضا'], 'وضعیت': True}

# چاپ ساختاریافته، منظم و رنگی داده‌ها در خروجی
parsikit.pretty_print(data, title="اطلاعات کاربران")
```

#### اعتبارسنجی دسته‌ای داده‌ها (Batch)
یک لیست بزرگ از دیتای خام رو همزمان ولیدیت کنید و گزارش تمیزی از موارد موفق و خطاها بگیرید:
```python
import parsikit

items = ["7730123452", "1111111111", "0010123451", "bad-code"]
report = parsikit.validate_batch(items, parsikit.NationalCode, silent=False)
# یک جدول و گزارش شیک از موارد معتبر و نامعتبر در ترمینال چاپ می‌کنه
```

#### لاگ‌های فارسی شیک و تمیز
لاگر پیش‌فرض سیستم رو جوری تنظیم کنید که کدهای ناخوانا تولید نکنه و فارسی رو تمیز نمایش بده:
```python
import parsikit

logger = parsikit.setup_logging("DEBUG")
logger.info("ثبت نام کاربر با موفقیت انجام شد.")
```

### ۲. فرمت‌دهی و تراز بصری فارسی (`pformat` و `persian_fstring`)
کاراکترهایی مثل نیم‌فاصله یا اعراب، پهنای فیزیکی روی مانیتور ندارن اما ایندکس رشته رو پر می‌کنن که باعث میشه تراز ستون‌ها به هم بریزه. پارسی‌کیت این محاسبات رو اصلاح می‌کنه.

#### تراز بی‌نقص متون حاوی نیم‌فاصله و اعراب
```python
import parsikit

# کلمه "کتاب‌‌ها" دارای نیم‌فاصله است (طول واقعی رشته 8 کاراکتر، اما پهنای دیداری آن 7 کاراکتر است)
# متد pformat پهنای دیداری رو ملاک قرار میده و ستون‌ها رو دقیقاً تراز می‌کنه:
aligned = parsikit.pformat("{:<10} | تراز شد", "کتاب‌‌ها")
print(aligned) # خروجی: "کتاب‌‌ها   | تراز شد"
```

#### تبدیل سریع اعداد به فارسی با پسوند قالب‌بندی
کافیه پسوند `fa` یا `p` رو به قالب‌هاتون اضافه کنید تا ارقام به صورت خودکار فارسی‌سازی بشن:
```python
import parsikit

# فرمت سه رقم سه رقم عدد و تبدیل همزمان به ارقام فارسی
print(parsikit.pformat("هزینه: {:>10,fa} ریال", 1500000))
# خروجی: "هزینه:  ۱،۵۰۰،۰۰۰ ریال"
```

#### فرمت‌دهی هوشمند شبیه به f-string پایتون
بدون نیاز به پاس دادن تک‌تک متغیرها، متغیرهای محلی و محیطی شما رو خودش تشخیص میده:
```python
import parsikit

name = "علی"
price = 12500

# به طور خودکار مقادیر name و price رو از اسکوپ برنامه می‌خونه و تراز می‌کنه:
formatted = parsikit.persian_fstring("کاربر: {name:<5} | قیمت: {price:fa} تومان")
print(formatted)
# خروجی: "کاربر: علی   | قیمت: ۱۲۵۰۰ تومان"
```

### ۳. اسلاگ‌ساز، فضاها و پاکسازی همه‌جانبه متن
پاکسازی کامل متن‌ها، تولید لینک‌های سئو و ذخیره دیتای استاندارد در دیتابیس.

#### ساخت اسلاگ‌های فینگلیش برای آدرس صفحات (SEO)
متون فارسی رو به بهترین معادل پینگلیش برای آدرس صفحات وب یا آدرس تصاویر تبدیل می‌کنه:
```python
import parsikit

# کلمات پرکاربرد رو خودش ترجمه می‌کنه و بقیه کاراکترها رو به فینگلیش شیک تبدیل می‌کنه
print(parsikit.slugify("آموزش وردپرس به زبان ساده"))
# خروجی: "amoozesh-wordpress-beh-zaban-sadeh"

print(parsikit.slugify("سلام دنیا 💕"))
# خروجی: "salam-donya"
```

#### پاکسازی و نویزگیری کامل متن (`clean_text`)
یک جاروبرقی واقعی برای دیتابیس! کاراکترهای عربی رو فارسی می‌کنه، نیم‌فاصله‌ها رو اصلاح می‌کنه، ارقام رو فارسی می‌کنه و کدهای مزاحم یونیکد رو دور می‌ریزه:
```python
import parsikit

dirty_text = "ي كافيه ك   کتاب  ها  ميباشد  ۱۱۲۳\n\n\n\nجدید  "
print(parsikit.clean_text(dirty_text))
# خروجی:
# "ی کافیه ک کتاب‌ها میباشد ۱۱۲۳
# 
# جدید"
```

#### نرمال‌سازی فضاهای خالی و پاراگراف‌ها
فاصله‌ها و خطوط خالی اضافی رو مدیریت کنید، با قابلیت حفظ ساختار پاراگراف‌ها یا مسطح‌سازی کل متن:
```python
import parsikit

raw_paragraphs = "خط اول\n\n\n\nخط دوم   با   فاصله\n\nخط سوم"

# حفظ فاصله‌ی بین پاراگراف‌ها (تبدیل خطوط خالی زیاد به تک خط خالی)
print(parsikit.normalize_whitespace(raw_paragraphs, keep_paragraphs=True))
# خروجی:
# "خط اول
# 
# خط دوم با فاصله
# 
# خط سوم"

# تبدیل کل متن به یک خط صاف بدون لاین بریک
print(parsikit.normalize_whitespace(raw_paragraphs, keep_paragraphs=False))
# خروجی: "خط اول خط دوم با فاصله خط سوم"
```

#### مبدل سراسری اعداد متن به فارسی یا انگلیسی

```python
import parsikit

text = "شماره تماس ما: 09123456789"
print(parsikit.convert_numbers(text, to="persian"))
# خروجی: "شماره تماس ما: ۰۹۱۲۳۴۵۶۷۸۹"

print(parsikit.convert_numbers("کد امنیتی: ۱۲۵۰۰", to="english"))
# خروجی: "کد امنیتی: 12500"
```

### ۴. اعتبارسنجی هوشمند و مخفی‌سازی اطلاعات حساس
ورودی‌ها رو اتوماتیک تشخیص بدید و دیتای حساس کاربران رو در کمال امنیت لاگ یا ذخیره کنید.

#### تشخیص‌دهنده‌ی هوشمند نوع داده ورودی (`detect`)
تک فرم‌های ورودی رو به صورت پویا کلاس‌بندی و شناسایی کنید:
```python
import parsikit

print(parsikit.detect("09123456789")) # خروجی: "mobile_number"
print(parsikit.detect("7730123452"))  # خروجی: "national_code"
print(parsikit.detect("ali@example.com")) # خروجی: "email"
print(parsikit.detect("192.168.1.1")) # خروجی: "ip" (پشتیبانی کامل از IPv4 و IPv6)
print(parsikit.detect("https://google.com")) # خروجی: "url"
print(parsikit.detect("یک جمله ساده")) # خروجی: None
```

#### ابزارهای مخفی‌سازی و ماسک کردن داده‌ها (Security)
بخش‌های حساس دیتای کاربرها رو قبل از نمایش عمومی یا ذخیره در فایل‌های لاگ ماسک کنید:
```python
import parsikit

# ماسک کردن شماره موبایل
print(parsikit.mask_mobile("09123456789"))
# خروجی: "0912***6789"

# ماسک کردن کارت بانکی (با حفظ قالب‌بندی استاندارد چانک‌ها)
print(parsikit.mask_card("6037991122334455", mask_char="X"))
# خروجی: "6037-99XX-XXXX-4455"

# ماسک کردن کد ملی (با حفظ قالب تراز شده)
print(parsikit.mask_national_code("7730123452"))
# خروجی: "773-****45-2"

# ماسک کردن آدرس ایمیل به صورت متناسب
print(parsikit.mask_email("kamrani.exe@gmail.com"))
# خروجی: "ka******e@gmail.com"
```

### ۵. مبدل تقویم، ابزارهای مالی، مرتب‌سازی و ری‌شیپر (قابلیت‌های نسخه‌های قبلی)
تمام قابلیت‌های قدرتمند نسخه‌های قبلی همچنان با همان ثبات و بدون هیچ تغییری پشتیبانی می‌شوند.

#### مبدل تقویم جلالی و زمان انسان‌پسند
```python
import parsikit
import datetime

# تبدیل میلادی به جلالی با سرعت بسیار بالا به دلیل استفاده از کش سیستم
jy, jm, jd = parsikit.gregorian_to_jalali(2026, 7, 5)
print(parsikit.format_jalali(jy, jm, jd, "YYYY-MM-DD"))
# خروجی: "1405-04-14"

# بررسی سال کبیسه جلالی
print(parsikit.is_jalali_leap(1403)) # خروجی: True

# نمایش زمان نسبی به زبان فارسی
posted_at = datetime.datetime.now() - datetime.timedelta(hours=3)
print(parsikit.humanize_relative_time(posted_at))
# خروجی: "۳ ساعت پیش"
```

#### بازآرایی متون برای موتورهای گرافیکی (Reshaper)
متون فارسی رو برای رندر کردن صحیح در انجین‌هایی که راست‌چین یا اتصال حروف رو پشتیبانی نمی‌کنن (مثل Pillow ،Pygame یا OpenCV) آماده کنید:
```python
import parsikit

shaped = parsikit.reshape_for_graphics("عَلِیّ", reverse=False)
print(shaped) # خروجی: "ﻋَﻠِﻲّ"
```

#### تراز بومی فیلدهای ورودی در GUI (Tkinter / PyQt / PySide)
تصحیح فرمت فیلدها و فاصله‌گذاری‌ها دقیقاً در همان لحظه‌ای که کاربر تایپ می‌کند، با حفظ موقعیت مکان‌نما (Cursor):
```python
import parsikit
from PySide6.QtWidgets import QLineEdit, QApplication

app = QApplication([])
card_input = QLineEdit()

# اصلاح خودکار ورودی کارت بانکی به محض تایپ کاربر به صورت "XXXX-XXXX-XXXX-XXXX"
parsikit.bind_persian_input(card_input, "card_number")

card_input.show()
app.exec()
```
